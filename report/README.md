# Project 4 Progress Report

This folder contains the Stage 2 progress report and the visual evidence used
in the report.

- `CS654_Project4_Progress_Report.docx` is the editable report.
- `CS654_Project4_Progress_Report.pdf` is the five-page PDF version.
- `video_frames_montage.png` contains three frames from a recorded evaluation episode.
- `build_plain_progress_report.py` can regenerate the DOCX when run from this folder.

The screenshots are from an evaluation episode recorded after training. The
JSON result file and learning curve remain the main evidence about training.
